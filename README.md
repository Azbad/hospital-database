# Hospital Database

A relational hospital database built with PostgreSQL as part of my SQL learning journey.

## Project Overview

This project models a hospital system and stores information about:

- Departments
- Doctors
- Rooms
- Nurses
- Receptionists
- Patients

## Database Structure

The database contains the following tables:

- Departments
- Doctors
- Rooms
- Nurses
- Receptionists
- Patients

The tables are connected using primary keys and foreign keys to represent relationships between hospital entities.

## Technologies

- PostgreSQL
- SQL

## Features

- Create and manage hospital records
- Store doctors and their departments
- Store patients and their assigned doctors, nurses and rooms
- Track patient admission and discharge dates
- Manage hospital departments and rooms
- Perform queries using SQL
